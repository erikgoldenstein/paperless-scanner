# Asset provenance

The Paperless Scanner logo artwork in `icons/` was created for this project
by Erik Goldenstein in 2026 and is released under GPL-3.0-or-later together
with the project source.

The files under `gen/schemas/` are generated Tauri schema and permission
metadata. They are kept in the repository to make builds and editor tooling
reproducible; regenerate them from the locked Tauri dependency when changing
Tauri versions and preserve any upstream notices.
