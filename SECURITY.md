# Security policy

## Supported versions

Security fixes are applied to the latest release and the default branch.
Older releases may not receive security updates.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's security advisory
reporting for this repository. If private reporting is unavailable, contact
the maintainer through the repository owner's GitHub profile before opening a
public issue.

Please include:

- the affected version or commit;
- operating system and installation method;
- a concise description of the impact;
- reproducible steps or a proof of concept; and
- any suggested mitigation.

Do not include Paperless URLs, API tokens, scanned documents, or other private
user data in a report.

Please allow reasonable time for triage and coordinated disclosure. There is
currently no bug bounty program.
